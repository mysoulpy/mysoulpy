## Как работаю

**Задача → требования и критерии готовности → первая версия → проверка сценариев → запуск и доработки.**

Прорабатываю логику продукта, подбираю инструменты, ставлю задачи ИИ-агентам и проверяю результат. Разработка через ИИ — рабочий процесс, а не эксперимент.

**В проектах:** Python, aiogram, aiohttp, SQLAlchemy, SQLite, APScheduler, Telegram Bot API / Mini Apps, Prodamus, Яндекс.Метрика, Electron, React, Vite, интеграции с LLM.
