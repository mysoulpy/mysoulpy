# Second Brain — голосовые мысли, структура и контент

[← Портфолио](https://github.com/mysoulpy) · [Запросить демонстрацию](https://t.me/kuznitsaa)

**Платформа:** Windows. **Версия локального проекта:** 0.5.0.  
**Моя роль:** идея, сценарии, требования, разработка через ИИ-агентов, ручное тестирование и подготовка установщика.  
**Статус:** рабочий личный продукт; установщик подготовлен, проведено первичное внешнее тестирование.

## Проблема

В обычных заметках пользователь сам раскладывает мысли по папкам и темам. Я хотел сначала свободно фиксировать идеи, а организацию записей поручить ИИ.

## Основной сценарий

**Alt+Q → окно поверх текущего приложения → диктовка → сохранение → автоматическое распределение по темам → подготовка контента.**

Голосовой ввод позволяет зафиксировать мысль без предварительного выбора папки. Настраиваемый провайдер LLM обрабатывает сохранённую запись и помогает развивать материал.

## Реализованные возможности

- Глобальная горячая клавиша и отдельное окно захвата мысли.
- Голосовой и текстовый ввод; локальное потоковое распознавание речи.
- Автоматическая группировка по темам и подтемам.
- Аналитика тем, включая просмотр активности за неделю и месяц.
- ИИ-инсайты по повторяющимся мотивам и гипотезы для дальнейшей работы.
- Подготовка контента в пяти форматах: тред, Reels, карусель, статья, Telegram-пост.
- Сохранение версий контента и публикация через Telegram-интеграцию.
- Windows-установщик.

## Архитектура

| Слой | Реализация |
|---|---|
| Desktop и горячая клавиша | Electron |
| Интерфейс | React + Vite |
| Хранение | sql.js / SQLite |
| Обработка мысли | Распознавание → классификация → тема/подтема |
| ИИ | Настраиваемые провайдеры и модели |
| Публикация | Telegram Bot API |

Записи хранятся локально. При использовании внешних LLM содержимое для обработки передаётся выбранному провайдеру. Для ИИ-функций требуется его настройка; локальный голосовой ввод — отдельный компонент.

## Результат и границы

Создано приложение, объединяющее захват мыслей, их организацию и создание контента. Подготовлен установщик, продукт продемонстрирован и опробован внешним пользователем. Пользовательская база и экономия времени пока не измерялись.

Это личный продукт на раннем этапе развития. Подробный разбор и демонстрация доступны по запросу; установщик, личные заметки, ключи и исходный код публично не распространяются.

Умение сформулировать прикладную проблему, связать голосовой ввод, локальное приложение, LLM и внешний сервис, а затем довести решение до устанавливаемого продукта с помощью ИИ-разработки.
